## 📖 Sobre o Projeto

O **Rei dos Jogos** é um projeto voltado para a introdução de ligas de e-Sports e ecossistema de games pedagógicos em instituições de Ensino Fundamental e Médio na Grande São Paulo.

A proposta deste trabalho foi **redesenhar e aprimorar um site existente**, elevando o nível da experiência do usuário (UX), a acessibilidade, o desempenho da página e a fidelidade visual aos padrões modernos da web.

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico:** Estruturação otimizada para SEO e acessibilidade (`aria-label`, landmarks semânticos).
- **CSS3:** Estilização modular com suporte a variáveis CSS e layouts responsivos via Flexbox e CSS Grid.
- **JavaScript (ES6+):** Manipulação DOM para menu responsivo e interatividade.
- **Git & GitHub:** Versionamento do código em equipe.

---

## ✨ Melhorias Aplicadas em Relação à Versão Anterior

- 🎨 **Design System & Estilização:** Unificação da paleta de cores e tipografia através de variáveis no CSS.
- 📱 **Responsividade:** Interface adaptada para navegação fluida em dispositivos móveis e desktops.
- ♿ **Acessibilidade:** Inclusão de atributos ARIA para leitores de tela e estrutura semântica limpa.
- 🚀 **Navegação Modular:** Separação clara entre a landing page institucional e as sessões específicas ("Para Escolas", "Torneios", "Parceiros").
